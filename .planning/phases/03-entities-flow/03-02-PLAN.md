<!-- Obsidian .canvas JSON format specification -->

从 ARCHITECTURE.md 和 03-RESEARCH.md Pattern 2:

```json
{
  "nodes": [
    {
      "id": "abc123def4567890",    // 16-char hex lowercase
      "type": "text",               // "text" | "file" | "group"
      "x": 0, "y": 0,
      "width": 300, "height": 200,
      "text": "**Chapter 1**",      // Markdown; 仅 type: "text"
      "color": "1"                  // Obsidian Canvas color preset '1'-'6'
    },
    {
      "id": "def456abc1237890",
      "type": "file",
      "file": "Dialogues/innkeeper.ncanvas",  // vault-relative path; 仅 type: "file"
      "x": 400, "y": 0,
      "width": 300, "height": 200
    }
  ],
  "edges": [
    {
      "id": "edge-xxxxxxxxxxxx",   // 16-char hex
      "fromNode": "abc123def4567890",
      "toNode": "def456abc1237890",
      "fromSide": "right",         // "top" | "right" | "bottom" | "left"
      "toSide": "left"
    }
  ]
}
```

从 03-RESEARCH.md:
- Node ID: 16-char hex lowercase；使用 crypto.randomBytes(8).toString('hex')（Node.js 内置）
- JSON 缩进: 使用 tabs (`\t`) 匹配 Obsidian Canvas 格式
- Canvas read-modify-write 必须 preserve 未知字段：解析 JSON 后 spread 现有 node properties，仅追加新节点
- 不使用 Obsidian 内部 Canvas node ID 生成 API；自己生成 ID
- `color` 字段可选；值为 "1"-"6" 字符串
