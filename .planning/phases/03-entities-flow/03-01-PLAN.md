    创建 `plugins/flow-tools/src/entity-templates.js`，导出 4 个模板生成函数。

    **模块签名和导出：**
    ```javascript
    // entity-templates.js — Markdown 模板生成器 for ENT-01 through ENT-05
    // 从 shared/schema/ 读取字段定义，生成带 YAML frontmatter 的 .md 内容

    const { CharacterFields, CharacterRequired } = require('../../../../shared/schema/character');
    const { LocationFields, LocationRequired } = require('../../../../shared/schema/location');
    const { QuestFields, QuestRequired } = require('../../../../shared/schema/quest');
    const { ItemFields, ItemRequired } = require('../../../../shared/schema/item');

    module.exports = { createCharacterMd, createLocationMd, createQuestMd, createItemMd };
    ```

    **每个函数的实现规则（apply to all 4）：**

    1. **参数解构** — 接收一个对象，解构出该实体类型的所有字段
    2. **YAML 字符串安全** — 所有字符串值必须用双引号包裹；内部双引号转义为 `\"`；使用模板字面量生成 YAML 行
    3. **数组值** — 使用 `[a, b, c]` 方括号语法（Obsidian YAML 解析器兼容）；空数组写为 `[]`
    4. **空值处理** — 空字符串写为 `""`；不要省略可选字段
    5. **tags** — 每个实体写 `tags: [type]`（character/location/quest/item）
    6. **body 内容** — H1 标题使用 `# {name}`；根据实体类型添加结构化 section（参见 golden files）；使用 `[[id]]` wikilink 引用相关实体
    7. **字段名 snake_case** — YAML frontmatter 中的字段名使用 snake_case（`appearance_scenes` 而非 `appearanceScenes`），因为 Obsidian 对 frontmatter 字段名大小写不敏感但 snake_case 更可读

    **createCharacterMd({ id, name, role, voice, notes, appearanceScenes }):**
    - YAML: id, name, role, voice, appearance_scenes, tags
    - 如果 notes 非空，在 YAML 中包含 `notes: "{转义后的值}"`
    - Body: `# {name}`, `**Role:** {role}`, `**Voice:** {voice}`, 如果 notes 非空加 `## Notes\n\n{notes}`, `## Speaker Scenes`（空 section，策划手动填充）

    **createLocationMd({ id, name, description, region, connectedLocations, notes }):**
    - YAML: id, name, description, region, connected_locations, tags
    - Body: `# {name}`, description, `**Region:** {region}`, `## 相关地点` section 列出 `[[locId]]` wikilinks，如果 notes 非空加 `## Notes\n\n{notes}`

    **createQuestMd({ id, name, description, questType, prerequisites, stages, giverCharacterId, involvedLocationIds, notes }):**
    - YAML: id, name, description, quest_type, prerequisites, stages, giver_character_id, involved_location_ids, tags
    - Body: `# {name}`, description, `**Type:** {questType}`, `## 任务阶段` 编号列表, `## 关联角色` wikilinks, `## 关联地点` wikilinks, 如有 notes 加 `## Notes`

    **createItemMd({ id, name, description, itemType, relatedQuestId, ownerCharacterId, notes }):**
    - YAML: id, name, description, item_type, related_quest_id, owner_character_id, tags
    - Body: `# {name}`, description, `**Type:** {itemType}`, 如有 relatedQuestId 加 `## 关联任务` wikilink, 如有 ownerCharacterId 加 `## 持有角色` wikilink, 如有 notes 加 `## Notes`
