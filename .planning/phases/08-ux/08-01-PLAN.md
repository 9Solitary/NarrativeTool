### Task 1: UX-01 — settings.js 浏览按钮

`plugins/narrative-tool/src/ui/settings.js`:
- Export Path 设置项在文本框旁加 `.addButton()`，文字「浏览…」。
- 点击：懒加载 `require('electron').remote.dialog`（顶层 require 保持引擎/测试环境纯净——settings.js 被 node 测试导入，顶层 `require('electron')` 会崩）。用 try/catch 包裹：
  ```js
  let dialog = null;
  try { dialog = require('electron').remote.dialog; } catch (e) { /* not in Obsidian desktop */ }
  ```
- `dialog.showOpenDialog({ title: '选择导出目录', properties: ['openDirectory', 'createDirectory'] })`，取 `result.filePaths[0]` 填入文本框并 `saveSettings()`。
- 若 dialog 不可用：`notify('文件夹选择器不可用，请手动输入路径', 'error')`。
- 注意：Export Path 支持绝对路径（fs 写入）和 vault 相对路径。系统选出来的一定是绝对路径，直接填入即可（paths.js 已支持绝对路径）。

### Task 2: UX-02 — 全面中文化

命令显示名（main.js，ID 不变）：
| ID | 旧名 | 新名 |
|---|---|---|
| export-current-dialogue | Export current dialogue | 导出当前对话 |
| batch-export-all-dialogues | Batch Export All Dialogues | 批量导出所有对话 |
| validate-references | Validate Flow→Dialogue references | 验证 Flow→对话引用 |
| create-character | Create Character | 创建角色 |
| create-location | Create Location | 创建地点 |
| create-item | Create Item | 创建物品 |
| create-quest | Create Quest | 创建任务 |
| create-flow-canvas | Create Flow | 创建 Flow |
| create-flow-fragment | Create Flow Fragment | 创建 Flow 片段 |
| open-flow-canvas | Open Flow Canvas | 打开 Flow 画布 |

右键菜单（main.js `_registerFileMenuHooks`）：
- Add dialogue node → 添加对话节点
- Add character/location/item/quest node → 添加角色/地点/物品/任务节点
- Open linked dialogue → 打开关联对话
- Open flow canvas → 打开 Flow 画布

状态栏（status-bar.js）：
- pending: `Narrative Toolchain` → `叙事工具链`
- exporting: `Exporting x/y...` → `导出中 x/y...`；无进度时 `导出中...`
- success: `✓ N exported` → `✓ 已导出 N 个`；有失败时 `✓ 已导出 N 个，M 个失败`
- failure: `✗ <message>`（消息本体由调用方中文化）；兜底 `✗ 导出失败`

设置页（settings.js）：
- Export Path → 导出路径；desc 中文化
- MED Enabled → MED 扩展语法；desc 中文化
- Export Scope Directory → 导出范围目录；desc 中文化

通知文案（main.js + commands/*）全部中文化，包括：
- `已迁移旧插件设置`（已是中文）
- batch/validate/export-current 的 notify 文案（去掉 `[NP]` 前缀）
- 实体创建流程的 prompt/cancel/成功提示
- Flow 创建流程的全部提示（'Create Flow cancelled (no name)' → '已取消创建 Flow（未输入名称）' 等）
- 文件菜单操作提示（'No .ncanvas files found in vault' → '库中没有 .ncanvas 文件' 等）
- auto-export.js 的 'Failed to parse .ncanvas JSON' → '无法解析 .ncanvas 文件（JSON 格式错误）'
- reference-validator 的 reason 字符串（'invalid canvas JSON'、'file not found'）中文化

### Task 3: UX-03 — 批量进度 + 具体错误

- `batch-export.js exportAllDialogues()` 增加可选第 5 参 `onProgress(count, total)`，每处理一个文件调用一次。
- main.js `batchExportAllDialogues()` 传入回调：`this.statusBar.setState('exporting', { count, total })`。
- 失败收集具体错误：返回 `{ exported, failed, errors: [{file, message}] }`；failure 状态栏显示第一个错误的消息，notify 列出失败文件数+首个错误。
- auto-export 失败路径：`${failCount} auto-export failed` → 中文 + 首个具体错误消息。
