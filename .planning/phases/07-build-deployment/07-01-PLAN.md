# 07-01 PLAN + SUMMARY: 一键构建 + output/ 部署目录

## 目标

- ENG-03：根目录 `npm run build` 一键完成 esbuild 编译（单步）
- ENG-02：构建产物自动落入 `output/narrative-tool/`（main.js + manifest.json + styles.css），可直接复制进任意 vault

## 实现

- 根 `package.json`（新建）：`build` → `node scripts/build.mjs`；`test` → `node --test "tests/*.test.js"`（node 自带 glob，跨平台）
- `scripts/build.mjs`（新建）：
  1. 前置检查 `plugins/narrative-tool/node_modules/esbuild`，缺失时提示 `npm --prefix plugins/narrative-tool install` 并退出
  2. `execFileSync(node, ['esbuild.config.mjs'], { cwd: plugins/narrative-tool })` 单步编译
  3. 清空并重建 `output/narrative-tool/`，复制 `main.js`、`manifest.json`、`src/styles.css → styles.css`（样式同时运行时注入，文件形式让 Obsidian 原生加载，双保险且幂等）
- `.gitignore`：新增 `output/`

- `npm test` → 310/310 通过
