## 问题 1：部署后功能全部"不存在"

**现象**：复制 narrative-tool、narrative-graph 部署后，搜索/节点 ID/连线锚点都找不到。

**原因**：三项编辑器功能实现在已弃用的 `NarrativeCanvas/` 里，正式环境启用的是 `plugins/narrative-graph/`——两套代码完全独立。执行时选错了目标组件。

**解决**：新建 `PLUGINS.md` 插件维护状态表（正式/弃用、各自职责、新功能改哪里），README 加指引；三项功能按 narrative-graph 的架构重新实现（搜索框挂 `.ng-toolbar`，状态存视图字段抗全量重渲染；toPort 存 link 上优先于节点级 `node.ports.input`，终点拖手柄走 `_afterMutation()` 进 undo）。

## 问题 2：告警"看不到"

**原因**：导出告警只进 DevTools 控制台（`console.warn`），Notice 只有计数，自动导出路径连计数都没有。

**解决**：告警条目改为结构化 `{ level: 'error'|'warn', text }`；红告警时状态栏常驻红色计数（不自动消失），点击弹 `WarningsModal` 列出全部诊断（含节点 id 与标题）；自动导出遇红跳过写文件，修复后自动恢复。

## 问题 3：Ctrl+F 两次失效

**第一次**：按键挂在画布容器 keydown 上，容器无焦点时不触发。改为 document 捕获监听 + 活动视图门控（`82a478c`）。

**第二次**：仍然无效。诊断方法——在 DevTools 分级注入 window 捕获 / document 捕获 / document 冒泡三个探针监听器，观察事件到达层级与 `defaultPrevented`。结果：只有 window 捕获触发且 `defaultPrevented=true`，document 级完全没收到。

**根因**：Ctrl+F 绑定了 Obsidian 核心命令「在当前笔记中查找」（对非 Markdown 视图是空操作，所以看起来没反应）；Obsidian 快捷键系统在 **window 捕获阶段**先执行该命令并 `stopPropagation()`，事件永远到不了 document。但 `stopPropagation` 不拦**同一 window 目标**上的其他监听器（诊断脚本注册更晚也收到了）。

**解决**（`666b935`）：监听从 document 捕获移到 **window 捕获**，与 Obsidian 处理器同目标同阶段，即使它先 preventDefault 我们仍能收到。实测通过。

## 经验规则

1. 改代码前先查 `PLUGINS.md` 确认组件维护状态；NarrativeCanvas 只读参考、不部署。
2. Obsidian 快捷键在 window 捕获阶段消费并 stopPropagation——插件要抢全局热键（如 Ctrl+F），必须注册在 **window 捕获**，document 级收不到。
3. 导出告警契约是 `{ level, text }`：红 = 导出必然错误/有损，阻断自动导出并常驻状态栏；黄 = 建议性。
4. 快捷键失效排查套路：分级注入探针监听器，定位事件被消费的层级。
